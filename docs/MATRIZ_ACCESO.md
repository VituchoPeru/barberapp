# Matriz de acceso por rol

Generada por `backend/tests/Integration/Security/AccessMatrixTest.php` a partir de las rutas reales; no la edites a mano.
La prueba falla si el acceso de algún rol cambia sin actualizar esta matriz.

Cuentas demo usadas: una por rol, con el contexto de la barbería `demo-centro`.

| Símbolo | Significado |
|---|---|
| S | Permitido: pasa los controles de acceso de la ruta (luego aplican las reglas del recurso, p. ej. el barbero solo ve sus citas) |
| L | Requiere iniciar sesión (401) |
| P | Sin permiso (403) |
| B | No es miembro de la barbería: 404 sin revelar que existe |
| - | No aplica: la cuenta no tiene perfil de barbero |
